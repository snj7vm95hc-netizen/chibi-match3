Chibi Match 3 — ဖုန်းအတွက် Chibi လူရုပ် Match-3 ဂိမ်း

ပါဝင်သည်
- ချစ်စရာ Chibi ယောက်ျားလေး/မိန်းကလေးပုံစံ 7 မျိုး
- ပုံတူ 3 ပုံနှင့်အထက်ကို အလျား/ဒေါင်လိုက် တွဲလျှင် ပျောက်ခြင်း
- အမှတ်တွက်စနစ်၊ Level တိုးစနစ်၊ ရည်မှန်းချက်၊ အလှည့် 20 ကြိမ်
- Restart ခလုတ်
- ဖုန်းမျက်နှာပြင်နှင့် ကိုက်ညီသည့် PWA project

iPhone မှာ App လိုထည့်ရန်
1. ZIP ဖြည်ပါ။
2. ဖိုင်အားလုံးကို HTTPS hosting (ဥပမာ GitHub Pages) ပေါ်တင်ပါ။
3. Safari မှာ site ကိုဖွင့်ပါ။
4. Share > Add to Home Screen ကိုနှိပ်ပါ။

မှတ်ချက်: ဒီဖိုင်က PWA/Web App project ဖြစ်ပါတယ်။ Native APK/IPA မဟုတ်သေးပါ။ App Store/Play Store ထုတ်ဝေဖို့ ထပ်မံ build လုပ်ရန်လိုပါတယ်။
